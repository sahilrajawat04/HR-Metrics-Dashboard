# HR Metrics Dashboard

An interactive Power BI dashboard I built at work to give leadership a clear view of headcount, attrition, and workforce demographics, used for recurring (bi-weekly) HR reporting.

> **Note:** The underlying data is company HR data, so it is not included in this repository. This repo contains screenshots and documentation only.

![HR Metrics Dashboard](dashboard(2).png)

## What it tracks

- **KPI cards:** average age, total headcount, and attrition rate
- **Attrition by department:** R&D, Sales, and HR
- **Job satisfaction by job role:** matrix view across roles
- **Employee count by age group and gender:** stacked bar chart
- **Attrition by education field:** bar chart
- **Attrition rate by gender across age groups:** donut charts
- **Education level slicers** to filter every visual at once

## Key findings

- **R&D accounts for 56% of all exits**, because it is the largest department. Sales has the highest attrition *rate* (about 21%).
- **Younger employees leave most:** about 39% of Under-25 employees left, followed by about 20% of the 25-34 group. Attrition drops to roughly 10% for ages 35-54.

## How it was built

1. **Cleaned and structured** the raw HR data so it could be reported on reliably.
2. **Built the Power BI report** with the visuals above, plus slicers for filtering.
3. **Delivered recurring reports** on a bi-weekly cadence, handed off to leadership for planning decisions. Cleaning and structuring the data in advance cut report prep time by roughly 15-20%.
